# sport-api

Microservicio de la plataforma [juan-in-one](https://github.com/juan-in-one) — retos deportivos, récords
personales e integración con la API de Strava.

Parte del stack de aprendizaje DevOps/DevSecOps/GitOps: Kubernetes + Helm + GitHub Actions (CI) + ArgoCD (CD)
sobre un clúster local en OrbStack.

Estado: en construcción.
